# Rules for this repository

**Name and id.** The mod is Eyes of Liberty, id `alomare.eyesofliberty` since 1.0.0 (repo `Alomare/HD1-EyesOfLiberty`, renamed from `HD1-UnleashedCamera`; the folder is `Mods/Session/EyesOfLiberty`). From 0.8.0 to 0.9.1 it was Unleashed Camera, id `alomare.unleashedcamera`, and until 0.7.0 Integrated Third Person, id `alomare.integratedthirdperson`. Obsidian refuses an update whose id differs from the installed one (`core/src/updates.rs` stage), so old installs stay on their last version until the player removes them; while an old id is loaded, this mod stays off (`env.off`). Custom Crosshair and Better HUD import the newest id first and the older ones after; Enhanced Visuals loads after `alomare.eyesofliberty` only.

**Branches.** `dev` and `main` carry the third person camera only. First person (`src/viewmodel.lua`, `src/fpanim.lua`, `src/pose.lua`, the First person options) lives on `firstperson`, which merges `dev` and is released only as betas (`v<next minor>-beta.N`, tagged on `firstperson`). The commit on `dev` that took first person out is merged into `firstperson` with `-s ours`, so merging `dev` there brings later changes without deleting it.

**Every release has a changelog.** Before tagging, add a section for the version to `CHANGELOG.md`, headed `## <version>`. Each change is one list item, starting `- New:`, `- Changed:`, `- Fixed:` or `- Removed:`, and describes the change briefly and directly. The shared Release workflow publishes that section as the release notes on GitHub, and stops if the section is missing or breaks the rules for public text.
